Find the formulas behind your data

Drop a spreadsheet and Regrex tells you which columns are computed from other columns, with which formula, and which rows break the rule.

Supported formats

  • CSV / TSV .csv .tsv .txt
  • Excel .xlsx .xlsm .xls .xlsb
  • OpenDocument .ods
  • JSON .json .ndjson .jsonl
  • Parquet .parquet .pq
  • Arrow / Feather .arrow .feather .arrows .ipc
  • SQLite .sqlite .sqlite3 .db

You can also paste cells copied from a spreadsheet (Ctrl+V).

Results

How the columns depend on each other

An arrow goes from each column to the columns computed from it. Select a computed column to go to its formula.

Copies of other columns

These columns hold the same values as another column, maybe shifted or scaled. They were found before the search and are not used as inputs, so they do not take the place of other columns.

    Suspicious rows

    These rows break a formula that almost every other row follows, so they are probably typing or copy mistakes. The cell that breaks the rule is highlighted.
