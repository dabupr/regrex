Find the formulas behind your data

Drop a spreadsheet and Regrex tells you which columns are computed from other columns, with which formula, and which rows break the rule.

Supported formats

What Regrex looks for

No AI and no guessing: every formula is checked on every row, and you see how many rows follow it.

ƒ Formulas between columns

subtotal = price × quantity, vat = 0.21 × net. Rows that break the rule are listed with the likely mistake, such as a rate typed as 0.1 instead of 0.21.

▤ A formula per type

When a text column such as curve_type decides the rule: 0 on straights, constant on each curve, a ramp on each transition curve.

↧ Between rows

When the rows follow an order: a running total, a chainage that grows by the distance between points, or a gradient that is the slope of the height.

Aa Text columns

A key made of two columns (line|track), codes that go with one name, numbers hidden in codes such as GIS5550, and columns that set another (each circuit has one interlocking).

⇄ Two files together

Add a second file and its rows are matched with the first on the columns both have, so you find that a measured value equals the designed one.

≈ Almost and approximate

Formulas that hold on part of the rows, and relations that only hold to within a small error, are shown apart, marked as such, with the error.

      How the columns depend on each other

      An arrow goes from each column to the columns computed from it. Select a computed column to go to its formula.

      Copies of other columns

      These columns hold the same values as another column, maybe shifted or scaled. They were found before the search and are not used as inputs, so they do not take the place of other columns.

        Relations between text columns

        Found on the text as written: keys made of other columns, codes that go with one name, and columns whose value is set by another.

          Almost: formulas that hold on part of the rows

          These formulas were not reported because they hold on too few rows, or only where another column has some values. They often show that the column follows different rules in different groups of rows. Search the rows where one fails to find what those rows follow.

            Suspicious rows

            These rows break a formula that almost every other row follows, so they are probably typing or copy mistakes. The cell that breaks the rule is highlighted.
