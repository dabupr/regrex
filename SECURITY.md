# Security Policy

## Supported versions

Regrex is in early development. Only the latest release (and `main`) receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/dabupr/regrex/security/advisories/new).

Include a description, steps to reproduce and, if possible, a minimal input file. You can expect a first answer within 7 days. Once a fix is released, the advisory is published with credit to the reporter (unless you prefer to stay anonymous).

## Scope

Regrex parses user-provided files (CSV, Excel) and expressions. Crashes, hangs or excessive memory use triggered by crafted input are in scope.
